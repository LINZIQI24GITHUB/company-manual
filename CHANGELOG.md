# Changelog

## 0.1.0

- Content-driven company manual: cover, business, income, balance/cash, sources.
- Demo entries: NVIDIA (FY2017–FY2026), Apple (FY2017–FY2026), Tesla (FY2016–FY2025), 中际旭创 (2016–2025), 宁德时代 (2016–2025), 贵州茅台 (2016–2025) and 中国平安 (2016–2025).
- Conditional sections for segment mix and capital allocation.
- 10-year revenue strips use a labelled log scale.
- Self-contained HTML with print CSS; A4 PDF output via browser print.
- Stdlib-only renderer; no API keys or network calls.
- The demo PDFs carry the bilingual disclaimer block (English + 中文): not investment advice, no buy/sell recommendation, historical results do not guarantee future performance.
- Data comes from public annual reports; adding a new company requires your own JSON snapshot.
- Unit tests and GitHub Actions render workflow.
- MIT license for code and templates.
