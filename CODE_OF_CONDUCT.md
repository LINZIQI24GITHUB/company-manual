# Code of Conduct

## Our standard

Be direct, factual, and respectful.

Examples of unacceptable behavior:

- harassment, personal attacks, or discriminatory language;
- submitting invented financial data or fake sources;
- using the project to promote a stock, fund, or trading strategy;
- publishing private or licensed data without permission.

## Scope

This applies to issues, pull requests, discussions, and any project space.

## Enforcement

Report concerns to `hi@finansi.work`. Maintainers may edit or remove contributions and may block accounts for repeated or serious violations.
