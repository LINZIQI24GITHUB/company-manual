## 字段来源

| 字段 | 取自 | 口径 |
|---|---|---|
| revenue | 合并利润表 "营业收入" | 报表顶行 |
| gross_profit | 营业收入 − 营业成本 | 计算值，非披露毛利行 |
| operating_income | 合并利润表 "营业利润" | 报表行项目 |
| net_income | 合并利润表 "归属于母公司所有者的净利润" | 归母口径 |
| assets / liabilities | 合并资产负债表 "资产总计" / "负债合计" | 期末值 |
| equity | "归属于母公司股东权益合计" | 归母权益 |
| total_equity | "所有者权益（或股东权益）合计" | 含少数股东权益 |
| cash | "货币资金" | 含受限资金，未剔除 |
| debt | 短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券 | 四项披露值相加（计算值） |
| ocf | 合并现金流量表 "经营活动产生的现金流量净额" | 报表行项目 |
| capex | "购建固定资产、无形资产和其他长期资产所支付的现金" | 取绝对值 |
| dividends / buybacks | 未单列 | 资本配置表省略 |
