# 贵州茅台（600519）数据来源与口径（2016–2025）

- 公司：贵州茅台酒股份有限公司（600519.SH，上交所）
- 口径：2025 年年度报告，合并报表；金额单位亿元，人民币
- 财年：自然年，2025 年截止 2025-12-31

## 字段口径

| 字段 | 口径 |
|---|---|
| revenue | 利润表“营业收入”（不含财务公司利息收入等“营业总收入”其他项） |
| gross_profit | 营业收入 − 营业成本（计算值） |
| operating_income | 利润表“营业利润” |
| net_income | 利润表“归属于上市公司股东的净利润” |
| assets / liabilities | 资产负债表“总资产”/“总负债”期末值 |
| equity / total_equity | “归属于上市公司股东的净资产”/“所有者权益合计” |
| cash | 货币资金 + 拆出资金（2019 年起公司将原计入货币资金的存放同业款项重分类至拆出资金，合计口径跨年可比） |
| debt | 短期借款 + 长期借款 + 应付债券 + 一年内到期的非流动负债；公司无有息借款，仅少量租赁负债 |
| ocf | 现金流量表“经营活动产生的现金流量净额” |
| capex | “购建固定资产、无形资产和其他长期资产支付的现金” |
| dividends | 当年宣告的现金分红合计（中期+年度+特别分红），来自分红送配数据 |
| buybacks | 未列示（无回购披露） |

## 核对结果

- 与 5 份年度报告（2017/2019/2021/2023/2025 年报）的“主要会计数据”逐项核对：**50 项全部一致，0 项不符**。
- 覆盖 2016–2025 全部 10 年，每年核对营业收入、归母净利润、经营现金流、归母净资产、总资产 5 项。
- 资产 = 负债 + 所有者权益（含少数股东）10 年全部精确相等。

## 说明

- 2019 年货币资金同比大幅下降是重分类所致（存放同业款项调整至拆出资金），合计数不呈下降。
- 分红为宣告口径，与现金流量表“分配股利、利润或偿付利息支付的现金”不同。
- 公司未披露分产品毛利，故不做分部表。
