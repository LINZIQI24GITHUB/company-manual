# 中国平安（601318）数据来源与口径（2016–2025）

- 公司：中国平安保险（集团）股份有限公司（601318.SH，上交所）
- 口径：2025 年年度报告，合并报表；金额单位亿元，人民币
- 财年：自然年，2025 年截止 2025-12-31

## 字段口径

| 字段 | 口径 |
|---|---|
| revenue | 利润表“营业收入” |
| gross_profit | 不适用：保险公司不披露营业成本/毛利，字段留空，页面显示“—” |
| operating_income | 利润表“营业利润” |
| net_income | 利润表“归属于母公司股东的净利润” |
| assets / liabilities | 资产负债表“资产总计”/“负债合计”期末值 |
| equity / total_equity | “归属于母公司股东权益合计”/“股东权益合计” |
| cash | 货币资金（不含拆出资金） |
| debt | 短期借款 + 长期借款 + 应付债券（2025 年合计 10,882.75 亿元） |
| ocf | 现金流量表“经营活动产生的现金流量净额” |
| capex | “购建固定资产、无形资产和其他长期资产支付的现金” |
| dividends | 当年宣告的现金分红合计（中期+年度）；2025 年 488.91 亿元，与年报披露一致 |
| buybacks | 未列示 |

## 核对结果

- 2025 年与 2017 年关键科目与年报合并报表逐项核对：营业收入、归母净利润、资产总计、负债合计、归母股东权益、经营现金流**12 项全部一致**。
- 2025 年分红总额 488.91 亿元与年报“现金分红总额”一致。
- 资产 = 负债 + 股东权益（含少数股东）10 年全部精确相等。

## 说明

- 保险公司报表无“营业成本/毛利”，毛利率不适用。
- 货币资金不含拆出资金（同业拆借，2025 年 2,729.95 亿元），属投资类资产。
- 有息负债含应付债券（资本补充债等），金额较大属行业常态。
